# bash-tools

[![GitHub release](https://img.shields.io/github/v/release/andresgongora/bash-tools)](https://github.com/andresgongora/bash-tools/releases)
[![License: GPLv3](https://img.shields.io/badge/license-GPLv3-blue.svg)](LICENSE)
[![Buy Me a Coffee](https://img.shields.io/badge/Buy_Me_a_Coffee-tip-yellow)](https://buymeacoffee.com/andresgongora)

Personal collection of Bash utility scripts for use in other projects. Find more details and similar tools on [Yet Another Linux'n Electronics Blog](https://yalneb.blogspot.com/).

Some script snippets may come from third parties. Individual scripts reference original authors when known. If you recognize an uncredited snippet, please get in touch.

<!--------------------------------------+-------------------------------------->
## Usage
<!--------------------------------------+-------------------------------------->

| Folder | Script | Description |
| ------ | ------ | ----------- |
| `/` | `color.sh` | Colorize and format command-line text. |
| `/` | `load_config.sh` | Retrieve script configuration from a file. |
| `/` | `edit_text_file.sh` | Add text to a file without duplicating it. |
| `/` | `print_utils.sh` | Print text blocks in terminal. |
| `/` | `shorten_path.sh` | Shorten path names without truncating them. |
